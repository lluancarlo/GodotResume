# Godot Resume
A interactive resume 3d made in Godot. </br>
It works on HTML5 and also support mobile browsers. </br>
The Input is basically WASD and on mobile you have the touch-input UI. </br>
Play it [HERE](https://lluancarlo.github.io/GodotResume) !
